| 項目 | 決定内容 | 理由 |

| サービス名 | ルアマケ（LureMake） | — |

### 技術スタック
| ツール/サービス | 採用理由 |
|---|---|
| **Laravel 11（PHP 8.2+）** | さくらのサーバ対応、日本語ドキュメント豊富、セキュリティ機能充実 |
| **Blade + Tailwind CSS + Alpine.js** | Laravelと一体で動く、スマホ対応容易 |
| **MySQL 8.0** | さくらのレンタルサーバ標準サポート |
| **PAY.JP** | 日本語サポート、トークン方式でカード情報をサーバに保存しない |
| **Git + GitHub（privateリポジトリ）** | コードの安全な管理 |
| **さくらのレンタルサーバ（スタンダードプラン以上）** | SSHアクセスが必要なため |

### 開発環境
| ツール | 採用理由 |
|---|---|
| **Laravel（PHP）** | さくらのレンタルサーバ（契約済み）がPHPをネイティブサポート。DjangoはさくらのレンタルサーバではCGIのみで実用的でないため |
| **Docker + カスタムdocker-compose.yml** | Laravel Sailのブートストラップコマンドがdocker-credential-desktopのPATH問題で失敗したため、既存プロジェクトのdocker-compose.ymlスタイルを参考に手動作成 |
| **Docker Desktop for Mac** | コンテナ実行に必要 |

### 認証・メール設定
| 項目 | 決定内容 | 理由 |
|---|---|---|
| 認証ライブラリ | Laravel Breeze（Blade構成） | 登録・ログイン・パスワードリセット・メール確認が標準装備。最小構成で導入できる |
| メールアドレス確認 | 有効（MustVerifyEmail実装） | スパムアカウント対策 |
| 開発環境のメール | MAIL_MAILER=smtp + Mailpit | 実メールアドレスへの誤送信を防ぐため、開発中はMailpitで横取りする |
| ログイン試行制限 | Breeze標準実装をそのまま使用（5回失敗でロックアウト、メール+IP単位） | 追加実装不要 |

### DB設計の判断
| 判断 | 内容 | 理由 |
|---|---|---|
| カテゴリ別属性 | JSONカラム（category_attributes）で管理 | 初期はシンプルに。パフォーマンス問題が出たら別テーブルに移行 |
| transactions.price | 取引時の価格を確定値で保存 | 後から価格変更されても取引履歴が変わらないようにするため |
| ソフトデリート | users・lure_comments・messages に適用 | トラブル対応・法的対応のためデータを物理削除しない |

### 法的対応（リリース前に必要）
| 対応事項 | 根拠 |
|---|---|
| 電気通信事業の届出（総務省） | メッセージ・コメント機能が「他人の通信の媒介」に該当する可能性 |
| 特定商取引法に基づく表記 | EC事業者として義務 |
| 利用規約・プライバシーポリシー | サービス運営の基本 |
| 資金決済法の確認 | PAY.JP利用で回避可能だが弁護士確認推奨 |
| 古物営業法の確認 | C2C仲介のため原則不要だが弁護士確認推奨 |
